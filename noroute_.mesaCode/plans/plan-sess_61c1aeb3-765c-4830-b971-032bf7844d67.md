Tambahkan reasoning compatibility layer generik seperti Agent Harness, tanpa memaksa semua request berpikir.

1. Provider config.
   - Tambah `reasoning` config: enabled, parameter mapping object (default `{ reasoning_effort: "$level" }`), summary parameter/value, supported levels, default level, and optional passthrough.
   - CodeBuddy default: levels `low`, `medium`, `high`, `xhigh`; mapping `reasoning_effort`; add `reasoning_summary: "auto"` only when a level is requested. `none/off` removes reasoning params.
   - Custom providers default passthrough/unknown; user can configure mapping in Edit provider.
2. Request transform in `src/routes/chat.js`.
   - Normalize incoming Agent Harness styles: `reasoning_effort`, `reasoning_level`, `thinking.level`, or `reasoning.level` into one level.
   - Apply provider mapping only when explicitly requested; never force reasoning on ordinary requests.
   - Preserve `tools`, `tool_choice`, `parallel_tool_calls`, system messages, and all other body fields unchanged.
   - Validate level against provider-supported list; unknown level returns 400 with supported levels.
   - Map `none/off` by removing mapped reasoning fields.
3. Response compatibility.
   - Preserve SSE `reasoning_content`, `reasoning`, and provider-native reasoning fields without hiding them.
   - Non-stream accumulator maps reasoning content into `reasoning_content`; no invented chain-of-thought.
4. Dashboard/provider editor.
   - Add Reasoning section: Smart/Auto toggle, levels chips, default level, mapping JSON, summary key/value. Show exact upstream mapping and “only applied when requested.”
   - Model capabilities show configured levels and provider format.
5. Tests/docs.
   - Smoke for low/high/none, alternate input normalization, invalid level, tools untouched, CodeBuddy summary injection, custom passthrough.
   - Document that proxy transports requested reasoning; does not generate hidden reasoning or execute agent tools.
6. Verify syntax, `npm test`, local stub request-body assertions, no real upstream.

Skipped: forcing a default reasoning level. That would change Agent Harness behavior and can increase latency/cost.
